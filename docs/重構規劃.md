## 2. 怎麼用

改完內容或樣式後，依序跑這三步：

```
node scripts/build.mjs            1. 產生 dist/（壓縮過的圖片，給稽核與預覽用）
python scripts/audit-content.py   2. 稽核 dist/：「找不到出處」必須是 0
node scripts/build.mjs --out .    3. 把正式成品輸出到 repo 根目錄
```

然後用 GitHub Desktop commit、push，GitHub Pages 會直接發布根目錄。

只有要重新從舊站抽內容時，才需要先跑 `python scripts/extract.py`（讀 docs/legacy/ 的舊 HTML，產生 data/events/*.json 與 data/home.json）。

本機預覽要用伺服器，不能直接雙擊 HTML（YouTube 會擋 file:// 的嵌入，顯示錯誤 153）：

```
python -m http.server 8080
```

在 repo 根目錄執行，再開 `http://localhost:8080/`。

### 日文版（2026-10-01）

- 網站有中文（`/`）、英文（`/en/`）、日文（`/ja/`）三語。日文是 AI 翻譯（Davie 同意），存在 `data/i18n/ja.json`，以中文原文（沒有中文時用英文）為 key，所以重跑 `extract.py` 不會洗掉。人名不翻。
- 改了中文或英文原文，要同步改 `ja.json`；`node scripts/build.mjs` 會列出缺少的日文翻譯，`audit-content.py` 會檢查每個 key 都對得到原文。
- 備用站 avatarmedicine.cancerfree.io（flightpath/avatarmedicine）用同一份產生器與 `ja.json`。

## 3. 上線與發布

GitHub Pages 維持「從分支根目錄發布」，不用改 Settings。第三步 `--out .` 會在根目錄產生或覆蓋這些檔案：

| 檔案 | 內容 |
| --- | --- |
| `index.html`、`en/index.html` | 中英首頁 |
| `2021/`、`2022/`、`2023/`、`en/2021/`～`en/2023/` | 各屆活動頁 |
| `404.html` | 找不到頁面 |
| `indextw.html`、`Forum2021～2023(.tw).html`、`2022/2023ForumpageTW/EN.html`、`EvaSelect2024.html` | 12 個舊網址的轉址頁 |
| `assets/site.css`、`assets/site.js` | 樣式與前端程式 |
| `sitemap.xml`、`robots.txt` | 搜尋引擎用（robots.txt 含 `Disallow: /docs/` 與 Sitemap 行） |

這些都是產生出來的檔案，不要手改，改 `data/` 或 `src/` 再重跑三步。

注意事項：
- **圖片沒有壓縮**：`--out .` 直接引用 `images/`、`2023_images/`、`documents/` 的原圖。頁面上用到的 40 張原圖合計約 31.5 MB，首頁圖片約 21.9 MB（7 張活動花絮是 4032×3024 手機原圖），og:image 主視覺 8.5 MB。`dist/` 版本壓縮後整站只有 4.2 MB。
- **整個 repo 都會公開**：從分支根目錄發布時，`data/`、`scripts/`、`src/`、`docs/`（含 `docs/legacy/` 的舊站與講者資料）都能直接用網址存取。robots.txt 只擋了 `/docs/`。
- **Jekyll**：分支發布預設會跑 Jekyll。目前檔案裡沒有 Liquid 語法，不會讓建置失敗，但 `.md` 檔會被轉成 HTML 頁面公開。如果想讓檔案原樣發布，可以在根目錄放一個空的 `.nojekyll`。
- 上線後，Google Search Console 與 Bing Webmaster Tools 的驗證 meta 已在每頁 `<head>`，再提交 `https://avatarmedicine.xyz/sitemap.xml`。

## 5. SEO 與導流

- 每頁有獨立的 title、description、canonical、hreflang（zh-Hant／en／x-default）、Open Graph。
- JSON-LD：首頁 `WebSite` + `Organization`；活動頁 `Event`、`FAQPage`、每支影片一個 `VideoObject`、`BreadcrumbList`。
- `sitemap.xml` 含 hreflang；`robots.txt` 指向 sitemap。
- 議程、講者、合作單位都是文字，不再是圖片。
